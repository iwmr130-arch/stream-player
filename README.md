# StreamPlayer

配信や画面共有で使うための動画／音声プレイヤーです（Windows / Mac）。

- ローカルの動画・音声ファイル（mp4, webm, mov, mkv, mp3, wav, m4a, flac, ogg など）と、YouTube / Vimeo の動画を再生できます
- **操作ウィンドウ**と**出力ウィンドウ**が分かれていて、出力ウィンドウには映像だけを表示します
- **メイン**（出力画面に表示）と **BGM**（音声だけ）の 2 系統のプレイリストを持ち、メインの再生中は BGM を自動で下げます（ダッキング）

詳しい仕様は [REQUIREMENTS.md](REQUIREMENTS.md) を参照してください。

## ダウンロードとインストール

[Releases](../../releases) から最新版をダウンロードします。

| OS | ファイル | 使い方 |
|---|---|---|
| Windows | `StreamPlayer-x.y.z-setup.exe` | インストーラー。スタートメニューとデスクトップにショートカットができます |
| Windows | `StreamPlayer-x.y.z-portable.exe` | インストール不要。そのまま起動できます（USB メモリなどから使う場合） |
| Mac | `StreamPlayer-x.y.z-mac.dmg` | 開いて、StreamPlayer を「アプリケーション」フォルダにドラッグします |

### 初回起動時の警告について

コード署名をしていないため、初回起動時に警告が出ます。

- **Windows**: 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します
- **Mac**: 「開けません」と出たら、「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある「このまま開く」を押します
  - それでも開けない場合は、ターミナルで `xattr -cr /Applications/StreamPlayer.app` を実行してから開きます

## 使い方

1. **メイン**に動画・音声ファイルをドラッグ＆ドロップするか、YouTube / Vimeo の URL を貼り付けて追加します
2. 項目をダブルクリックすると、出力ウィンドウで再生が始まります
3. 項目ごとに「終了後」の動作（停止／次へ／ループ）を選べます。停止すると出力画面は待機画面に戻ります
4. **BGM** に音楽ファイルを追加して ▶ を押すと、裏で流し続けます（全体ループ／1 曲ループ／シャッフル）
5. リストの項目は、ドラッグで並べ替えられます

### 出力ウィンドウ

画面上部の「出力」で表示方法を選びます。

- **ウィンドウ（画面共有用）**: 普通のウィンドウとして表示します。枠がないので、画面のどこをつかんでも移動でき、端をドラッグすると大きさを変えられます
  - Zoom では「画面の共有」でこのウィンドウ（StreamPlayer 出力）を選び、「コンピューターの音声を共有」をオンにします
- **全画面（配信用）**: 「表示先」で選んだディスプレイに全画面で表示します。マウスカーソルは出ません

出力ウィンドウを閉じても、「出力ウィンドウを表示」で戻せます。

### ショートカットキー（操作ウィンドウを選んでいるとき）

| キー | 動作 |
|---|---|
| Space | メインの再生／一時停止 |
| Esc | メインを停止 |
| Ctrl+→ / Ctrl+←（Mac は ⌘） | メインの次へ／前へ |
| B | BGM の再生／一時停止 |

### 設定

「設定」ボタンから変更できます。

- **ダッキング**: メイン再生中の BGM の動作（音量を下げる／一時停止する／何もしない）、下げたときの音量、フェード時間
- **待機画面**: メインを再生していないときに出す画像（未設定なら黒い画面）
- **プレビュー**: 操作ウィンドウに出力画面の縮小表示を出すかどうか
- **エクスポート／インポート**: 設定とプレイリストを JSON ファイルに保存し、別の PC で読み込めます。別の PC でファイルの場所が変わった場合は、「見つからないファイルをフォルダから探す」で、同じ名前のファイルを探して付け直せます

### 注意

- YouTube / Vimeo の動画は公式の埋め込みプレイヤーで再生します。埋め込みが禁止されている動画は再生できません
- ローカルファイルは、Chromium が対応しているコーデックのみ再生できます（H.264 / VP8 / VP9 / AV1 の動画、AAC / MP3 / Opus / Vorbis / FLAC / PCM の音声）。avi や一部の mkv（H.265 など）は再生できないことがあります
- 他の人の動画を配信で流すときは、権利者の許諾と配信サービスの規約を確認してください

## 開発

Node.js 22 以上が必要です。

```sh
npm install        # 依存パッケージを入れる
npm start          # ビルドして起動する
npm run typecheck  # 型チェック
npm run dist:win   # Windows 版のインストーラーとポータブル版を release/ に作る
npm run dist:mac   # Mac 版の dmg を作る（Mac 上でのみ実行可能）
```

### リリース手順

1. `package.json` の `version` を上げます（例: `0.2.0`）
2. コミットして、同じ番号のタグを push します

   ```sh
   git tag v0.2.0
   git push origin main --tags
   ```

3. GitHub Actions が Windows 版と Mac 版をビルドし、Releases に登録します

main ブランチに push するたびに、両 OS 版のビルドが Actions の Artifacts にも保存されます（リリース前の確認用）。

### 構成

```
src/
  main/        メインプロセス（ウィンドウ管理、保存、ローカル HTTP サーバー）
  preload/     画面に公開する API
  renderer/
    control/   操作ウィンドウ（プレイリスト、BGM 再生、設定）
    output/    出力ウィンドウ（ローカル / YouTube / Vimeo の再生）
  shared/      共通の型と URL 解析
scripts/build.mjs   esbuild でのビルド
```

画面とローカルのメディアファイルは、`127.0.0.1` に限定したローカル HTTP サーバーで配信しています。`file://` で読み込むと、YouTube の埋め込みがリファラーなしで拒否されるためです。メディアの URL には起動ごとに変わるトークンを付け、他のアプリから読まれないようにしています。
